COMO SUBIR ESSA PASTA PRO SEU REPOSITORIO NO GITHUB
=====================================================

1. Extraia este zip em algum lugar do seu PC.

2. Abra o terminal DENTRO da pasta "backend" (a que tem o package.json).
   - No VS Code: Arquivo > Abrir Pasta > selecione "backend", depois Ctrl + `

3. Rode estes comandos, um de cada vez:

   git init
   git add .
   git commit -m "Primeiro commit - projeto base backend"
   git branch -M main
   git remote add origin https://github.com/kakafls007-bit/pratica-fullstack-backend.git
   git push -u origin main

4. Se pedir login, autorize pelo navegador que vai abrir.

5. Depois do push, atualize a pagina do GitHub (F5) pra conferir.

IMPORTANTE: o arquivo .env (com a senha do banco) NAO vai subir pro GitHub,
porque ele esta listado no .gitignore. Isso e proposital, nao mexa nisso.

Para rodar o projeto localmente antes de subir:
   npm install
   npm run dev    (ou: npm start)
